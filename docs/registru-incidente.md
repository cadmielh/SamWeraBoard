# Registrul incidentelor de securitate

Se completează pentru **orice** incident, chiar dacă nu se notifică autoritatea (GDPR art. 33 alin. 5). Nu se scriu date personale în acest registru: doar numere și categorii.
Procedura: [procedura-incident.md](procedura-incident.md).

| ID | Luat la cunoștință (data, ora) | Sursă | Descriere factuală | Spații afectate | Categorii de date / nr. persoane | Risc evaluat | Cabinete notificate (data, ora) | ANSPDCP notificat de operator? | Conținere / remediere | Închis (data) | Învățăminte / acțiuni |
|---|---|---|---|---|---|---|---|---|---|---|---|
| _(niciun incident înregistrat)_ | | | | | | | | | | | |

## Cum se completează
- **ID**: `INC-AAAA-NN` (ex. `INC-2026-01`).
- **Luat la cunoștință**: momentul de la care curg termenele de 24 h (evaluare), 48 h (cabinete) și 72 h (ANSPDCP, pentru operator).
- **Risc evaluat**: scăzut / mediu / ridicat, cu motivul într-o propoziție (CNP + act de identitate = ridicat implicit).
- Păstrează o copie a comunicărilor trimise (fără date personale) și a exportului jurnalului de acces într-un loc securizat, separat de acest registru.
